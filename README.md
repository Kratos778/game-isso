# Game Oi 🎮

Coleção de jogos simples e divertidos para telemóvel e PC.

**Site ao vivo:** https://game-isso.netlify.app/

## Jogos incluídos

| Jogo | Descrição |
|------|-----------|
| 🃏 **Memória** | Encontra os pares — 3 níveis de dificuldade |
| ❓ **Quiz** | 25 perguntas (Angola + gerais) |
| 🐍 **Snake** | O clássico com controlos touch + teclado |
| ⭕ **Jogo da Velha** | Contra o computador |
| ✊ **Pedra, Papel e Tesoura** | Melhor de muitos |
| 🔢 **Adivinha o Número** | Entre 1 e 100 |
| ⚡ **Reflexo** | Testa a tua velocidade de reação |
| 🧠 **Personalidade** | Descobre o teu tipo |

## Características

- Totalmente offline (depois de carregar)
- Guarda recordes no navegador (localStorage)
- Design responsivo (telemóvel e PC)
- Sem dependências externas

## Como correr localmente

Basta abrir o `index.html` no navegador.

## Deploy

O site está hospedado no Netlify: [game-isso.netlify.app](https://game-isso.netlify.app/)
